## Sum of elements

## Approach:
    - Initialize sum with zero.
    - Traverse array from index 0 to n - 1.
    - Add each element of array into sum one by one.
    - After traversal, sum contains the sum of all elements of array.

## TC:
    - O(n) -> Traversal of whole array at least once.

## SC:
    - O(1) -> No extra memory is utilized only sum, i is used which is constant space.

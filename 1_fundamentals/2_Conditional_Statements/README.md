# Types of Conditional Statement
    - 1 If Conditional Statement
    - 2 If-Else Conditional Statement
    - 3 if-Else-if Conditional Statement
    - 4 Switch Conditional Statement
    - 5 Ternary Expression Conditional Statement

## Rules of the Switch Statement
    - 1 When using switch statements, there are a few important rules.
    - 2 Case values must be constant values.
    - 3 Duplicate case values are not allowed.
    - 4 A switch statement can contain multiple case blocks.
    - 5 The break statement is optional, but recommended to prevent fall-through.
    - 6 The default case is optional but useful for handling unexpected values

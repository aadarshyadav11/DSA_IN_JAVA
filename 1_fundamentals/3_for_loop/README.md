# for loop
    - A for loop allows you to repeat a block of code a specific number of times
    - Widely used when the number of iterations is known in advance

## for loop has three main parts:
    - initialization
    - condition
    - updation 

## Types of for loop
    - basic for loop 
    - for Each loop: used to iterate directly over elements
    - for loop with multiple variables
    - infinite for loop: runs infinitely due to no terminating condition   
    - nested for loop: used for multi-dimensional data

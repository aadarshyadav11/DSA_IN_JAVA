# Common method of Scanner class
    - 1. nextInt() : used for reading integer value
    - 2. nextFloat() : used for reading float value
    - 3. nextDouble() : used for reading double value or decimal numbers
    - 4. next() : used for reading a single word
    - 5. nextLine() : used for reading sentences value
    - 6. nextLong() : used for reading Long value
    - 7. nextBoolean() : used for reading Boolean value
